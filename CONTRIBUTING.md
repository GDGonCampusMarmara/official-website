# Contributing to GDG on Campus Marmara University

First off, thank you for considering contributing to our community project! It’s people like you that make this community such a great place to learn, share, and build together.

---

## Tech Stack & Core Modules

Before you start, please familiarize yourself with our core development stack:

- **Core Framework:** [React (Vite)](https://react.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Routing:** [React Router Dom](https://reactrouter.com/)
- **Performance Tracking:** [Google Lighthouse](https://web.dev/measure/)

---

## Code Style & Standards

To maintain a clean and maintainable codebase , we follow these standards:

1.  **Component Structure:** Always use functional components with hooks.
2.  **Naming Conventions:**
    - **Components:** `camelCase` (e.g., `eventsCard.jsx`)
    - **Functions/Variables:** `camelCase` (e.g., `handleFilterChange`)
    - **Hooks/Utils:** `camelCase` (e.g., `useScrollSpy.js`, `calcPos.js`)
    - **Files:** Use `.jsx` for React components and `.js` for hooks/utils.

## Contribution Guidelines

Please follow these steps to ensure a smooth contribution process:

### 1. Fork & Clone

- **Fork** the repository to your own GitHub account.
- **Clone** your fork locally:
  ```bash
  git clone [https://github.com/your-username/official-website.git](https://github.com/your-username/official-website.git)
  ```

### 2. Branching

- Create a new branch for your work. Use a descriptive prefix:
  ```bash
  git checkout -b feat/your-feature-name
  # or
  git checkout -b fix/issue-name
  ```

### 3. Develop & Test Locally

- Install dependencies: `npm install`
- Run the dev server: `npm run dev`

### 4. Commit

- We follow **Conventional Commits**. Please use the following command to format your commits correctly:
  ```bash
  npm run commit
  ```

### 5. Push & Pull Request (PR)

- Push your changes to your fork:
  ```bash
  git push origin feat/your-feature-name
  ```
- Open a **Pull Request** against our `main` branch with a clear description of your changes.
